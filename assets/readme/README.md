# README 界面配图

这些 PNG 使用 Easy Job 1.3.44 的实际扩展界面生成，均为离线 mock 演示。

- 使用独立浏览器配置目录，没有读取日常浏览器中的账号、Cookie、配置或扩展数据。
- 岗位、公司、招聘者、简历、话术和统计均为人工构造的虚构数据。
- 页面与求职期望请求由本地 mock 直接返回，其他 HTTP 请求全部阻断，没有访问真实 BOSS 或模型服务，也没有连接本机日志接收器。
- 每张图均带有 `MOCK DATA · 虚构数据 · 非真实投递结果` 标记。
- 图片仅展示界面和操作位置，不作为真实平台发送、采集覆盖、回复率或账号安全的验收证据。

| 文件                | 展示内容                     |
| ------------------- | ---------------------------- |
| `overview.png`      | 投递控制、进度与来源效率     |
| `sources.png`       | 搜索与求职期望来源           |
| `greeting.png`      | 自定义话术和 AI 开关         |
| `profile.png`       | 求职定位与虚构简历           |
| `pacing.png`        | 最低间隔和批量休息           |
| `records.png`       | 岗位处理记录                 |
| `record-detail.png` | JD、过程与实际话术的详情视图 |
